# v1.13

Restructure and clean-up release. No geometry change: every manufacturing report and every DXF outline of the ten presets (full hardware and direct-contact levels, all three input architectures) is byte-identical to v1.12.

## One design file plus libraries
- `src/cycloidal_gearbox.scad` holds the Customizer parameters and the part selector; the implementation lives in `src/lib/` (catalog, derived, cycloid, checks, report, parts_2d, parts_3d, views). Only the main file is parsed by the Customizer.
- Presets moved to `src/cycloidal_gearbox.json`.
- The versioned copies (`*_v1_6`, `*_v1_8`, `*_v1_9`, `*_v1_10`) are gone. Earlier versions are the merge commits on `main`:

| Version | Commit |
| --- | --- |
| v1.10 | [`694eb76`](https://github.com/DrFlGd/Cycloidal-Drive/commit/694eb76) integrated double-eccentric coupled shaft |
| v1.11 | [`6ce59a6`](https://github.com/DrFlGd/Cycloidal-Drive/commit/6ce59a6) geometry, fit, sleeve and export corrections |
| v1.12 | [`b5e4499`](https://github.com/DrFlGd/Cycloidal-Drive/commit/b5e4499) input support bearings |
| v1.13 | [`e95cf22`](https://github.com/DrFlGd/Cycloidal-Drive/commit/e95cf22) library split, legacy removal, CI |

- `docs/data/` keeps one current copy of each table: `PROFILE_GUIDE.csv` (generated by `tools/profile_guide.py`), `INPUT_SHAFT_OPTIONS.csv`, `INTEGRATED_SHAFT_NOTES.md`, `validation_matrix.csv`. Empty and superseded CSVs were removed.

## Legacy paths removed
- `hardware_catalog_mode` ("Legacy preset dimensions"): bearing sizes always come from the catalog.
- `use_frame_preset` / `custom_*` motor fields: `motor_frame` selects the NEMA table, `CUSTOM` uses the custom fields.
- `ratio_preset` + `custom_ratio` became `reduction_ratio`.
- `ring_roller_system` ("Compact hardened sleeves"), the `compact_ring_*` baseline fields and the fabricated-sleeve BOM path: ring rollers are catalog bearings; the housing grows only by the packing growth of the pitch circle.
- `printed_ring_feature_style` ("Legacy narrow bridges") and `printed_ring_bridge_width`: case lobes are always case-rooted.
- `Auto` options of the eccentric, output roller, flange and ring bearing selectors (they picked sizes that did not match the presets); `bearing_closure_preference`, `ring_bearing_closure_note`, the `active_*` and `ecc_motor_bore_d` aliases and the hard-coded commodity-preset echo lines.
- The build report prints `Design version:`; the SPEC header carries `version=1.13` and no longer reports the removed catalog/ring-system modes.

## Tooling
- `.github/workflows/render-openscad-docs.yml` now runs `tools/validate_presets.py` and exports the default preset's parts on every push and pull request, and re-renders `docs/images/` on `main` with `tools/render_docs.sh`.
- README rewritten around the current design with working image links.
